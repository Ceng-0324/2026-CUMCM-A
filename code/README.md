# 代码索引

代码按职责和题目分层，公共求解器不复制到各题目录。

| 目录 | 内容 | 入口 |
|---|---|---|
| [`common/`](common/) | 只读输入、统一径向求解器、历史原型、审计与工程检查 | `make check`、`make probe` |
| [`q1/`](q1/) | Q1 正式结果生成、独立温度基准、图件和物理假设复核 | `make q1` |
| [`q2/`](q2/) | Q2 变物性全场求解与图件 | `make q2` |
| [`q3/`](q3/) | Q3 连续域达标事件、表 5 和图件 | `make q3` |
| [`q4/`](q4/) | Q4 收缩域事件、实际半径输出和四组合机制对照 | `make q4` |

`common` 提供共享实现；Q1–Q4 目录只存放对应问题的专属代码。历史选题代码仍在 `archive/selection/`，不属于当前入口。

阅读计算代码时，先看 [公共模型的公式与函数对应](common/README.md)，再进入各问的 `run`：Q1 对照独立热方程基准，Q2 检查变物性时空场，Q3 延长积分并定位阈值，Q4 加入材料收缩和四组合对照。工作簿导出、图件和报告生成放在每问入口中，便于从一条结果追溯到计算与验证。

修改公共数值核心后，先用 `make test` 检查物性、通量、守恒和采样，再执行 `make probe`、`make q1` 至 `make q4` 更新正式来源，最后运行 `make verify`。重构时另将全精度场、表格、事件和验证指标与改前快照比较，不能只更新代码哈希。Q3/Q4 的 `validation_sensitivity.json` 属于独立运行的证据；正式入口保留其索引和原始来源，参数或模型改变时须另行复核。

## 代码维护约定

- 按数学职责拆分函数，保留 `rho`、`cp`、`km`、`rhs` 等领域惯例；只处理确实难以辨认的名称。
- 注释说明公式适用条件、单位、符号方向和数值陷阱，删除复述语句的文字。调试残留和无明确事项的 TODO 不进入正式代码。
- 输入损坏或求解失败应明确报错，保留原始异常；敏感性试验临时修改共享参数或方法时，用 `finally` 恢复。
- Q3 采样极值、Q4 逐段多项式极值和历史原型单元极值各有适用范围，不为代码形式统一而混用。
