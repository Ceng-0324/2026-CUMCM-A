# 选题阶段归档

本目录保存选题期间五份报告、代码、题面文本快照和数值证据，内容保留当时状态。当前唯一有效的分析为 [A题思路分析总文档](../../reports/ANALYSIS_MODELING_REPORT.md)。

| 目录 | 内容 |
| --- | --- |
| reports/ | 三题分析、选题分析、A/C 再分析、选题综合结论、A 主线与创新设计 |
| code/ | 历史 selection_audit.py、selection_probes.py |
| sources/ | 先前从题面和附件提取的文本快照 |
| results/original/ | 当时的文件清单、输入审计、A/C 复核和可行性/机制试算 |

旧报告的 C 优先判断、旧路径、假设和选题推断保留历史语境；后续已有修正，以新总文档为准。旧文中的相对路径未批量改写，不保证从归档位置可直接执行。B/C 原始资料已不在当前项目，历史提取文本不等于完整原始输入。

当前 A 专用入口在 `code/`，结果在 `results/probes/`。新工程保留两份 A 原型数值快照作为迁移回归基准；源码哈希和运行环境记录以新结果为准。不得继续维护两套活动代码或从旧报告覆盖有效总文档。
