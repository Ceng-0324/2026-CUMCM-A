# Q1 算法与建模方法概览

> 本页是论文手的快速入口，回答“问题一具体用了哪些模型和算法”。详细推导见 [problem1_algorithm_analysis.md](problem1_algorithm_analysis.md)，数值证据见 [RESULTS_REPORT.md](RESULTS_REPORT.md)。

## 方法定位

Q1 是固定半径药材在预热阶段的径向热质传递问题。模型采用一维圆柱径向条件模型：附录 2 的密度、比热和导热系数取常数，水分扩散率仍随含水率变化；温度场和含水率场在数学上解耦，可分别推进。

**数学本质**：一个固定圆柱域上的热扩散方程与非线性水分扩散方程，其中温度方程为常系数、含水率方程的扩散率为 $D(C)$。**算法本质**：用环形有限体积把圆柱散度方程转成共享界面通量的守恒常微分方程，再用 Kirchhoff 变换处理 $D(C)$ 的非线性，最后用隐式 BDF 推进刚性时间系统。

## 方法清单

| 层次 | 具体方法 | 解决的问题 | 本问状态 |
|---|---|---|---|
| 物理建模 | 一维圆柱径向模型、中心对称、表面 Robin 换热/传质 | 将有限圆柱简化为主要径向传递，同时保留表面阻力 | 已采用；端部和有效平衡浓度为条件假设 |
| 空间离散 | 圆柱环形有限体积法 | 保留面积因子 $r$，避免 $r=0$ 奇异项，并形成逐面守恒通量 | 已验证 |
| 非线性通量 | Kirchhoff 积分 $K(C)=\int_0^C\exp(-a/s)\,\mathrm ds$ | 在表层浓度梯度较大时稳定处理 $D(C)$ 的非线性 | 已验证 |
| 表面处理 | 最外半控制体 + Robin 边界联合求解，Brent 标量求根 | 区分最后一个单元中心和真实表面，避免强行赋值 | 已验证 |
| 时间推进 | 带稀疏雅可比结构的 BDF 隐式积分 | 处理热扩散与慢水分扩散造成的刚性 | 已验证 |
| 连续输出 | PCHIP/Hermite 重构；水分在 $K(C)$ 空间重构后反解 | 输出任意半径位置的中心值和真实表面值 | 已验证 |
| 结果验证 | 网格加密、时间收紧、独立圆柱热基准、Robin 残差和干基水量收支 | 区分数值离散一致性与物理假设有效性 | 已完成 |

## 计算链条

题面与附录参数 → 单位检查和环境输入分段线性插值 → 环形有限体积离散 → 计算热/水分界面通量 → 求解表面边界状态 → BDF 推进 → 连续场采样 → 工作簿、表 1/2 和图件 → 网格、时间和守恒验证。

## 论文手应突出的方法关键词

正文第一次出现时建议明确写出：**圆柱环形有限体积法、Kirchhoff 非线性积分通量、表面半控制体 Robin 边界、BDF 隐式积分、$K(C)$ 空间连续重构**。不要只写“采用数值方法求解”，那样等于把做过的工作主动抹掉。
