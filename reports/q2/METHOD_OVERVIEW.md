# Q2 算法与建模方法概览

> 本页是论文手的快速入口，回答“问题二具体用了哪些模型和算法”。详细推导见 [problem2_algorithm_analysis.md](problem2_algorithm_analysis.md)，数值证据见 [RESULTS_REPORT.md](RESULTS_REPORT.md)。

## 方法定位

Q2 是附录 3 变物性条件下的温度—含水率双向耦合问题。计算从共同初值重新开始，不接续 Q1 末态；含水率 $C$ 改变 $\rho,c_p,k$，温度与含水率共同改变 $D(T,C)$，因此两个场必须联合推进。

**数学本质**：固定圆柱域上的变系数、双向耦合热质扩散 PDE；$C$ 改变热方程系数，$T$ 和 $C$ 共同决定水分扩散率。**算法本质**：把 $T,C$ 合成联合状态，在每个隐式时间层同步更新物性和界面通量；Kirchhoff 变换只处理浓度非线性，温度因子保留在通量中，因此没有把耦合问题拆成两个独立模型。

## 方法清单

| 层次 | 具体方法 | 解决的问题 | 本问状态 |
|---|---|---|---|
| 物理建模 | 附录 3 变物性热质耦合 PDE | 描述含水率改变热物性、温度反过来影响水分扩散的反馈 | 已采用 |
| 空间离散 | 圆柱环形有限体积法 | 保留圆柱几何权重并保证相邻控制体共享界面通量 | 已验证 |
| 水分通量 | 分解 $D(T,C)=A(T)\exp(-a/C)$，对浓度因子作 Kirchhoff 积分 | 保留 $C$ 非线性，同时保留温度因子 $A(T)$ 的耦合 | 已验证 |
| 热界面系数 | 导热系数调和平均 | 处理随含水率变化的界面热阻 | 已验证 |
| 表面处理 | 半控制体 Robin 边界 + Brent 求解表面含水率 | 使变物性内部通量与表面通量连续 | 已验证 |
| 联合时间推进 | BDF 隐式积分 + 稀疏雅可比结构 | 处理双场耦合和刚性，按附件 1 的 60 s 节点分段积分 | 已验证 |
| 输出重构 | 温度直接重构，$K(C)$ 重构后单调反解为 $C$ | 得到论文指定的非单元中心位置结果 | 已验证 |
| 结果验证 | $N=512/1024/2048$ 网格、收紧时间设置、正性、水量收支和 Robin 残差 | 检查耦合求解与边界实现的一致性 | 已完成（前 3 h） |

## 计算链条

共同初值与附录 3 参数 → 当前状态计算 $\rho,c_p,k,D$ → 环形有限体积热/水分通量 → 非线性表面求根 → 联合 BDF 推进 → 每秒、每 $0.1$ cm 连续采样 → 表 3/4 和三张图 → 网格、时间与守恒验证。

## 论文手应突出的方法关键词

正文应明确写出：**变物性双向耦合、联合状态推进、Kirchhoff 浓度积分通量、调和平均导热系数、表面半控制体 Robin 边界、稀疏 BDF、连续场重构**。Q2 不能简写成“在 Q1 基础上延长计算”，它改变的是方程耦合结构。

## 结果边界

正式表 3/4 覆盖前 3 h；完整达标事件由 Q3 单独定位。Q2 的数值收敛验证针对当前条件模型，不等于附录 3 经验物性或有效表面平衡浓度已经得到实验确认。
