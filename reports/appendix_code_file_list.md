# 附录：支撑材料代码文件清单

以下清单依据 `submission_support/` 的当前内容整理，供论文手直接放入论文附录。文件按“主入口 → 直接依赖 → 独立复核”排序；四问共用的代码只在第一部分列出，避免重复。下列路径均相对于支撑材料根目录。

## A.1 公共复现入口与数值核心

四个问题均依赖以下文件，建议首先列出并按顺序阅读：

1. `run.py`：统一复现入口，负责接入并核验赛题原始附件，分别重算 Q1–Q4，并将新生成的未舍入场与随包正式结果比较。
2. `code/common/data_io.py`：只读解析 Excel，核验输入文件 SHA-256，并统一写出 JSON。
3. `code/common/audit.py`：检查附件字段、时间轴、工作表结构与数值范围。
4. `code/common/model.py`：四问共用的数值核心，包含圆柱环形有限体积、附录 2–4 物性、Kirchhoff 水分通量、Robin 边界、BDF/Radau 时间积分、连续场重构以及收缩材料坐标。
5. `code/common/plotting.py`：统一数据图的字体、缓存目录和 PDF 输出设置。

## A.2 问题一：预热阶段温度与含水率分布

1. `code/q1/problem1.py`：问题一正式运行入口；完成空间和时间加密、正式求解、表 1/2、`result1.xlsx`、未舍入场数据及结果摘要输出。
2. `code/q1/q1_validation.py`：问题一入口调用的独立温度级数基准、场差异、端部效应和守恒诊断。
3. `code/q1/plot_q1.py`：从正式场数据生成径向剖面、位置历程、时空分布和收敛图。
4. `code/q1/q1_physics_audit.py`：对有效平衡浓度、湿空气换算和潜热情景进行独立物理复核；用于说明模型边界，不替代正式结果。

问题一的公共数值核心和结果比较入口分别见 A.1 中的 `code/common/model.py` 与 `run.py`。

## A.3 问题二：变物性热质耦合

1. `code/q2/problem2.py`：问题二正式运行入口；从共同初值求解附录 3 变物性热质耦合模型，完成网格和时间对照、表 3/4、`result2.xlsx`、未舍入场数据以及全部问题二结果图输出。

问题二的有限体积、Kirchhoff 通量、耦合时间推进和连续场采样由 A.1 中的 `code/common/model.py` 提供，因此无须重复列出专属辅助文件。

## A.4 问题三：全域含水率首次达标时间

1. `code/q3/problem3.py`：问题三正式运行入口；延长附录 3 固定半径模型，重构连续含水率场，扫描阈值变号区间并用 Brent 法定位首次达标事件，输出表 5、`result3.xlsx`、事件误差和结果图。

问题三的参数敏感性和 BDF/Radau 交叉复核由 A.6 中的 `code/common/model_validation_sensitivity.py` 完成；重算结果由 `run.py` 与正式未舍入场比较。

## A.5 问题四：考虑收缩的烘干过程

1. `code/q4/problem4.py`：问题四正式运行入口；在材料坐标中求解时变半径模型，定位全域达标事件，输出表 6、`result4.xlsx`、四组合机制结果和结果图。
2. `code/q4/q4_sensitivity.py`：复核环境延拓口径，以及固定/收缩半径与附录 3/4 物性四组合的网格收敛性。
3. `code/q4/q4_interpolation_sensitivity.py`：比较分段线性与 PCHIP 半径插值对达标时刻的影响。

问题四还使用 A.6 中的参数敏感性程序；重算结果由 `run.py` 与正式未舍入场比较。

## A.6 跨问题敏感性与交叉复核

1. `code/common/model_validation_sensitivity.py`：统一执行 Q3/Q4 的换热系数、传质系数和扩散率前因子扰动，并用 BDF 与 Radau 交叉核对事件时刻。

## A.7 非代码运行文件

以下文件不属于源程序，不计入上述代码编号，但应与代码一并放入支撑材料：

1. `pyproject.toml`：声明 Python 版本范围和直接依赖。
2. `uv.lock`：锁定完整依赖版本，保证计算环境可重复建立。

## 附录中建议保留的简短说明

赛题提供的题面与附件不重复放入支撑材料。复现时由 `run.py` 根据正式结果摘要中的来源哈希接入原始附件，再调用各问正式程序；Q1–Q4 的新输出写入独立的 `reproduced/` 目录，不覆盖随包提供的正式结果。四问共用同一数值核心，各问脚本只增加相应的物性、事件判据或收缩几何处理。
